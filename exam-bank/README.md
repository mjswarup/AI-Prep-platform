# Placement Exam Paper Bank

This folder stores previous-year technical and written assessment material that can be mixed into a placement-prep assessment flow.

## Purpose
- Keep a structured archive of previous-year paper patterns
- Mix technical and written sections into a combined mock assessment
- Support placement preparation across coding, aptitude, reasoning, and verbal ability
- Allow future assessment generation using a weighted combination of historical patterns

## Suggested structure
- `papers/index.json` – metadata catalog for all paper sets
- `papers/technical/` – technical papers, coding, DSA, DBMS, OOP, OS, networking
- `papers/written/` – aptitude, reasoning, verbal, case-based written sections

## Recommended usage
1. Select a subject mix by company pattern
2. Build question sets from previous-year papers
3. Randomize question order while preserving difficulty balance
4. Use a timer and anti-cheating guardrails during assessment
5. Review analytics after submission for weak areas and improvement

## Example categories
- DSA
- DBMS
- Operating Systems
- Computer Networks
- Aptitude
- Logical Reasoning
- Verbal Ability
- Communication / Written English
