# Previous Year Technical Paper - DSA

## Section A: Coding Fundamentals

1. Explain the time complexity of binary search and when it fails.
2. Write a function to reverse a linked list in-place.
3. Find the longest substring without repeating characters.
4. Given an array of integers, find the maximum subarray sum using Kadane's algorithm.
5. Explain the difference between BFS and DFS and give a use-case for each.

## Section B: Data Structures

6. Implement a stack using two queues.
7. Describe the use of hash maps in optimizing lookup operations.
8. Write code for a min-heap insertion and extraction.
9. Solve a tree traversal problem using inorder, preorder, and postorder.
10. Explain collision handling in hash tables.

## Section C: Problem Solving

11. Given a sorted array, find the first and last position of a target value.
12. Explain how dynamic programming differs from greedy algorithms.
13. Given a matrix, count the number of connected components.
14. Design an efficient solution for top K frequent elements.
15. Analyze the complexity of merge sort and quick sort.

## Suggested evaluation pattern
- Easy: 30%
- Medium: 50%
- Hard: 20%
